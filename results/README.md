# Experimental results

Recorded sensor data, position estimates, and plots from nine experiments. The experiment directories retain their original IDs and data filenames.

Directory names follow `exp<trial>_<scenario>`: the first number identifies the trial, and the second identifies the scenario (`1` = LOS, `2` = WLOS, `3` = NLOS). For example, `exp2_1` is the second trial under LOS conditions.

## Directories

| Directory | Contents |
| --- | --- |
| `exp1_1/`, `exp2_1/`, `exp3_1/` | LOS (line of sight), trials 1 to 3 |
| `exp1_2/`, `exp2_2/`, `exp3_2/` | WLOS (one wall), trials 1 to 3 |
| `exp1_3/`, `exp2_3/`, `exp3_3/` | NLOS (heavily obstructed), trials 1 to 3 |
| [sample_rate/](sample_rate/) | LOS, WLOS, and NLOS reception summaries and their comparison plot |
| [diagnostics/](diagnostics/) | The three acceleration diagnostic images previously stored in `backend/` |

## Data files

Each experiment contains the first six files below. The dead-reckoning output is present only in `exp1_1/`.

| File | Contents |
| --- | --- |
| `imu_data_1.csv` | IMU samples: `timestamp_ns`, quaternion components `qw`, `qx`, `qy`, `qz`, and acceleration components `ax`, `ay`, `az` |
| `uwb_data_1.csv` | UWB range measurements: `timestamp_ns`, `mac_address`, `distance` |
| `mqtt_ground_truth.csv` | Reference positions and movement state: `timestamp_ns`, `time_s`, `state`, `gt_pos_x`, `gt_pos_y`, `stop_number` |
| `merged_imu_uwb_data.csv` | IMU samples with relative time `t_sec` and sparse UWB columns `dist_48e72`, `dist_83a8d`, `dist_e05a1` |
| `ekf_results.csv` | EKF estimates: `timestamp_ns`, `pos_x`, `pos_y` |
| `trilat_results.csv` | Trilateration estimates: `timestamp_ns`, `pos_x`, `pos_y` |
| `imu_dead_reckoning.csv` | IMU-only estimates: `timestamp_ns`, `pos_x`, `pos_y` |

Timestamps ending in `_ns` are in nanoseconds. Positions and ranges are in metres. Ground truth is assigned to detected stops along a predefined path and interpolated between stops; it is generated by [ground_truth.py](../backend/collection/ground_truth.py).

## Scripts

Shared processing and analysis scripts live in [backend](../backend/README.md). Identical copies were removed from the experiment directories. Use these replacements from any `results/exp*` directory:

| Previous local script | Shared command | Purpose |
| --- | --- | --- |
| `plott_erros.py` | `python ../../backend/analysis/plot_errors.py` | Error statistics, error-over-time plot, and CDF |
| `sample_rate_uwb.py` | `python ../../backend/analysis/sample_rate_uwb.py` | Reception summary within the ground-truth time window |
| `run_tril.py` | `python ../../backend/processing/run_trilateration.py` | UWB-only position estimation |

Experiment-specific script versions remain beside their data. Their source code and settings are preserved; misspelled filenames were corrected.

| Script | Location | Purpose or difference |
| --- | --- | --- |
| `compare_errors_smoothness.py` | All nine experiment directories | Local versions of the error and trajectory comparison, with differences in comments, formatting, or documentation |
| `plot_errors.py` | `exp1_1/`, `exp1_2/`, `exp1_3/`, `exp2_1/`, `exp3_3/` | Error comparison variants retaining their original plot layouts and annotations |
| [plot_errors_alternative.py](exp2_2/plot_errors_alternative.py) | `exp2_2/` | Alternative error plot layout; previously `plott_erros_copy.py` |
| [plot_stop_errors.py](exp1_3/plot_stop_errors.py) | `exp1_3/` | Local trilateration stop-phase analysis, including interactive display |
| [run_ekf.py](exp2_2/run_ekf.py) | `exp2_2/` | EKF with initial state `(x, y, vx, vy) = (2.4, 4.1, 0, 0)`, rather than the shared script's `(2.07, 0.70, 0, 0)` |

## Running an analysis

Install the dependencies listed in the [backend README](../backend/README.md). Scripts read from and write to the current working directory, overwriting outputs with the same names.

From the repository root, use the retained versions for experiment 1.3:

```bash
cd results/exp1_3
python plot_errors.py
python compare_errors_smoothness.py
python plot_stop_errors.py
```

For an experiment without a local error-plot script:

```bash
cd results/exp2_3
python ../../backend/analysis/plot_errors.py
```

Run each example block from the repository root. To compare the stored sample-rate summaries:

```bash
cd results/sample_rate
python ../../backend/analysis/plot_sample_rate_comparison.py
```

This comparison script was previously named `results/sample_rate/plott_sample_rate`.
To preserve the stored plots and estimates while experimenting, use the scratch-directory example in the backend README.
